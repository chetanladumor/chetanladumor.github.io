1. Executive Summary & Architectural Motivation

In modern engineering teams, peer pull request (PR) reviews are notorious bottlenecks. Monolithic LLM prompts typically suffer from context dilution, overlooking subtle edge-case concurrency bugs, memory leaks, unindexed queries, or OWASP Top 10 vulnerabilities.

This platform treats code analysis as a distributed cooperative multi-agent workflow. By splitting the review task into five independent domain-specific agents (Security, Quality, Performance, Architecture, and DevOps) orchestrated via LangGraph, the system delivers structured, reproducible, and explainable feedback directly onto code diffs.

2. End-to-End System Architecture

Because LLM inference across five agents requires 8–20 seconds of compute time, GitHub webhook requests must never block synchronously on AI execution. The ingestion pipeline is decoupled using BullMQ and Redis:

Phase 01

Webhook Ingress & Replay-Proof Queueing

< 40ms Immediate Ack
📥 GitHub Inbound

Webhook triggers on pull_request.opened or synchronize with signed payload.

🔒 Cryptographic Ingress

Verifies HMAC SHA-256 signature; enforces MongoDB delivery ID uniqueness to prevent replay attacks.

⚡ Decoupled Enqueue

Pushes job into BullMQ (Redis) and returns HTTP 202 Accepted instantly to prevent GitHub webhook timeouts.

Phase 02

Diff Tokenization & Scope Boundary Filtering

Sub-200ms Preparation
🐙 Octokit Fetch

BullMQ worker assumes GitHub App installation JWT to fetch complete PR diff and commit metadata.

🧹 Context Pruning

Automatically strips lockfiles (package-lock.json), minified scripts, and binaries to conserve token window.

📊 State Initialization

Seeds LangGraph memory state with normalized unified diffs and an empty typed findings array.

5 specialized agents (Security, Performance, Architecture, Quality, DevOps) execute in parallel threads.

🎯 Schema Enforcement

Structured output parsing via Zod validates line numbers, rule categories, severity, and suggested patch diffs.

🔄 Thread-Safe Reducer

LangGraph's state reducer merges findings asynchronously into the shared state without data clobbering.

< 500ms Synthesis & Dispatch

Aggregator eliminates overlapping suggestions and filters out findings with confidence scores below 75%.

Archives latency and token telemetry in MongoDB; broadcasts completion event to dashboard via Socket.IO.

3. Why LangChain + LangGraph?

Understanding the distinction between LangChain and LangGraph is fundamental to enterprise agentic systems:

  • LangChain (Component Level): Handles model abstraction (swapping between Claude 3.5 Sonnet, GPT-4o, and DeepSeek via OpenRouter), structured prompt formatting, and Zod output parsing.
  • LangGraph (Orchestration Level): Manages the Stateful Graph Workflow. It provides a shared memory state, enables concurrent agent branches, and merges output arrays atomically using mathematical state reducers.
💡 The State Reducer Pattern

Instead of agents clobbering shared memory, LangGraph defines a findings channel backed by a state reducer function. When Security completes analysis, it appends its vulnerabilities. When Performance finishes 2 seconds later, it appends its latency findings. The graph guarantees thread-safe, non-destructive state accumulation across parallel workers.

4. Key Engineering Challenges Solved

1

Webhook Security & Idempotency

Guarded against spoofed payloads by verifying HMAC SHA-256 signatures against the GitHub App secret. Stored GitHub's X-GitHub-Delivery GUID in MongoDB with a unique index to guarantee that duplicate webhook retries are discarded instantly.

2

Structured Output Validation with Zod

Unstructured LLM text cannot be reliably mapped to code diff lines. All agents return strict Zod schemas defining file, lineNumber, severity, message, and confidenceScore. If validation fails, automated error-correction loops re-query the model.

3

Dynamic Multi-Model Routing via OpenRouter

Security and Architecture analysis benefit from deep reasoning models (Claude 3.5 Sonnet / GPT-4o), whereas Quality and DevOps checks run efficiently on faster, lightweight models. OpenRouter provides dynamic routing with automated rate-limit failovers.
